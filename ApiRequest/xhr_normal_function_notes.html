XMLHttpRequest — Normal Function

1. What is XMLHttpRequest?

The XMLHttpRequest object is used to make HTTP requests from JavaScript to a server/API.

It allows us to send a request and receive data without refreshing the entire webpage.

2. readyState

0 → UNSENT
    Client has been created.
    open() has NOT been called.

1 → OPENED
    open() has been called.

2 → HEADERS_RECEIVED
    send() has been called.
    Response headers are available.

3 → LOADING
    Response body is being downloaded.

4 → DONE
    Request is complete.

3. Important Methods

new XMLHttpRequest()

Creates the XHR object.

open()

Configures the request. It does NOT send the request. 

xhr.open("GET", requestUrl);

onreadystatechange

This event runs whenever the readyState changes.

send()

Actually sends the request to the server.

responseText

Contains the server response as a string.

JSON.parse()

Converts a JSON string into a JavaScript object.

4. Normal Function Example

const requestUrl =
    "https://api.github.com/users/hiteshchoudhary";

// Step 1: Create XHR object
const xhr = new XMLHttpRequest();

console.log("1. XHR created");
console.log("readyState:", xhr.readyState);
// 0 → UNSENT


// Step 2: Configure request
xhr.open("GET", requestUrl);

console.log("2. open() called");
console.log("readyState:", xhr.readyState);
// 1 → OPENED


// Step 3: Track state changes
xhr.onreadystatechange = function () {

    console.log(
        "3. onreadystatechange → readyState:",
        this.readyState
    );

    if (this.readyState === 4) {

        console.log("4. Request completed!");

        console.log(
            "5. responseText:",
            this.responseText
        );

        // JSON string → JavaScript object
        const data = JSON.parse(this.responseText);

        console.log("6. Parsed data:", data);
        console.log("Name:", data.name);
        console.log("Followers:", data.followers);
    }
};


// Step 4: Send request
console.log("7. Calling send()...");
xhr.send();

console.log(
    "8. Immediately after send():",
    xhr.readyState
);

5. Why can we use this.responseText?

This is a normal function: 

xhr.onreadystatechange = function () {
    ...
};

Unlike an arrow function, a normal function can have its own this.

For this XHR event handler, this refers to the XHR object.

Therefore we can write:

this.readyState
this.responseText
this.status

6. Execution Flow

new XMLHttpRequest()
        ↓
readyState = 0
        ↓
open()
        ↓
readyState = 1
        ↓
send()
        ↓
readyState = 2
        ↓
readyState = 3
        ↓
readyState = 4
        ↓
responseText
        ↓
JSON.parse()
        ↓
JavaScript Object

7. Important Observation

send() starts the request, but JavaScript does not wait for the server response.

Therefore, this: 

xhr.send();

console.log(xhr.readyState);

can print 1 immediately after send(). Later, when the server responds, the onreadystatechange function runs and you see states such as 2, 3, and 4.
